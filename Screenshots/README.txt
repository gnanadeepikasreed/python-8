
# Manufacturing Cost and Profitability Analysis

## Description
This project calculates manufacturing costs and analyzes the profitability of multiple products.

## Features
- Calculates material cost.
- Calculates labour cost.
- Calculates wastage cost.
- Calculates total manufacturing cost.
- Calculates selling amount.
- Identifies profit or loss.
- Checks profit target.
- Displays production summary.

## Concepts Used
Variables, data types, operators, conditional statements, loops, and lists.

## Language
Python 3

## How to Run
python Manufacturing_Cost_Analysis.py
